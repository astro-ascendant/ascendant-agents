# opencode-ascendant

Ascendant Vedic astrology for OpenCode: a KP-first skill, an `/ascendant` slash command, and two calculation tools (`ascendant_add_person`, `ascendant_check_transit`) that run `astro-ascendant` in-process with no child processes or shell scripts.

## Install

```sh
opencode plugin add opencode-ascendant
```

or pin a version:

```sh
opencode plugin add opencode-ascendant@1.0.0
```

Requires OpenCode v2. See the full method guide at https://astro-ascendant.vercel.app/docs/skills.
