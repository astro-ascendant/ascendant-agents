# opencode-ascendant

Ascendant Vedic astrology for OpenCode: a KP-first skill, an `/ascendant` slash command, and two calculation tools (`ascendant_init_person`, `ascendant_check_transit`) that run `astro-ascendant` in-process — no child processes, no shell scripts.

## Install

```sh
opencode plugin add opencode-ascendant
```

or pin a version:

```sh
opencode plugin add opencode-ascendant@1.0.0
```

Requires OpenCode v2. See the full method guide at https://ascendant-docs.vercel.app/docs/skills.
